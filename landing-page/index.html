Requirement 1 • Enterprise Deployment

One-Command Enterprise Deployment

Deploy the complete self-hosted stack on a fresh cloud project in an India region with a single command, including database, backups, updates, and monitoring. Anyone at Tatvic can repeat the deployment for a new client in under 15 minutes.

Pillar 1: Infrastructure

Cloud & Database

Terraform automated VPC, subnets, static IP, and e2-standard-4 VM in India (asia-south1). Production MariaDB 10.11 database with utf8mb4 collation and Redis session caching.

Zero cloud lock-in: toggle to local Docker Compose.
Pillar 2: Disaster Recovery

Automated Backups

Automated database dumps and state capture scheduled daily at 02:00 IST via Cloud Scheduler to GCS bucket with 90-day retention lifecycle. 30-day local rotation prevents disk exhaustion.

CLI: oydk backup • Restore: oydk restore <archive>
Pillar 3: Maintenance

Zero-Downtime Updates

Automated OS security patches via unattended-upgrades. Engine update engine executes pre-update safety backups before applying database migrations (core:update).

CLI check: oydk update --check-only
Pillar 4: Reliability

Cloud Monitoring

Google Cloud Monitoring 300s uptime probe on ingress URL with alert policy. Unified single-screen operational health status for database, backups, watermarks, and engine.

Health dashboard: oydk health

Decoupled Intellectual Property Architecture

"Your IP is not in the open-source tool itself, but in the deployment kit, the connectors and the migration agent. Keep those separate so they can be pointed at a different stack later."

01

Universal Stack Adapter Protocol

The core kit interacts strictly with abstract interfaces (AnalyticsStackAdapter). It never makes proprietary hardcoded assumptions about Matomo or PostHog.

  • • kit/adapters/posthog_adapter.py (Priority 2)

Autonomous GA4 Migration Agent

Harvests custom dimensions and conversion goals via Google Analytics Admin APIs, provisions them in the target engine, and stages tags as an unpublished draft workspace in GTM.

  • • Executive markdown audit report output
03

Continuous Parity & Tag Diagnostics

Compares GA4 vs the new stack daily on users, sessions, key events, and channels (target: ±5%). When numbers diverge, an autonomous rules engine diagnoses why and gives the fix.

  • • Diagnoses broken GTM tags & trigger conditions
India DPDP Act (Effective 12 May 2027)

DPDP-Ready Defaults Built-In

"DPDP-ready, never DPDP compliant"
✓ Consent Gated

Zero tracking requests fire until the visitor grants consent in CMP banner (Google Consent Mode v2 denied).

✓ PII Stripping

Phone numbers (+91 / standard) and emails are stripped from URLs and event parameters before logging.

✓ Retention Limits

Configurable retention policies (default: 365d) purging raw logs automatically. Managed via oydk retention.

✓ DSAR Rights Flow

Verified CLI lookup and permanent deletion of database rows across raw visit logs via PrivacyManager.

✓ Immutable Audit

Every lookup, erasure, retention change, and backup is recorded to an immutable SQLite audit trail.
